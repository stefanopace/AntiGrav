# AntiGrav Framework

Reusable base for Pebble watchfaces.
It includes basic behaviors shared across them:

- a basic clock and date
- multiple flicks to reveal the seconds
- watch and phone battery tracking
- step tracking
- a multi-tab Clay configuration page
- a mechanism for applying settings changes

It extends Pebble's single-subscription model so that more than one component can receive events from the same model. Use AntiGrav and AntiGrav mini as a usage example.
